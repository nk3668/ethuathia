## Summary
The Library building's Tactics tree, spent in Renown, unlocks new rule conditions, new actions and more rule slots per adventurer.

## Why
The player starts with a few slots and a small vocabulary, and the Library grows both (`CLAUDE.md` §4, §5.2).

## Acceptance criteria
- [ ] A starter vocabulary and slot count, with everything else locked behind Library nodes
- [ ] The editor shows locked conditions and actions with what they need
- [ ] The Library is a Tactics tree and can be redone for free between runs (ETH-086)
